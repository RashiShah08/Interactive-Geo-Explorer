# Interactive Geo Explorer

## Overview
Interactive Geo Explorer is a Python-based app for exploring geographical data via interactive maps and a chatbot with Open API integration. Features two modes: India Map and World Map, plus a chatbot for dynamic queries.

## Features
- **India Map**: Interactive India map; click states to view world records (cultural, natural, historical).
- **World Map**: Click coordinates to explore famous places by continent.
- **Chatbot**: Uses Open API to answer geography-related queries.
- **Tech Stack**: Python, Folium/Plotly, requests, Streamlit (optional).

## Requirements
- Python 3.8+
- Libraries: `folium`, `plotly`, `requests`, `streamlit`
- Open API key
